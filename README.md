# 🌍 EcoRescate · Proyecto ODS 13

Aplicación web CRUD + Juego educativo desarrollada en JavaScript puro utilizando arquitectura MVC y Programación Orientada a Objetos.

El proyecto está basado en el ODS 13 (Acción por el Clima) y busca concienciar sobre la correcta gestión y reciclaje de residuos mediante una aplicación interactiva y un minijuego gráfico.

---

# 🚀 Características

## 📋 CRUD de residuos
- Crear residuos
- Listar residuos
- Modificar residuos
- Eliminar residuos
- Filtrar residuos
- Persistencia con localStorage

## 🎮 Juego gráfico
- Residuos animados en pantalla
- Clasificación en contenedores
- Sistema de puntuación
- Velocidad aleatoria
- Aparición dinámica de residuos
- Eventos de ratón y teclado
- Drag & Drop

---

# 🛠️ Tecnologías

# 🎮 Cómo jugar

1. Inicia el juego desde el menú principal.
2. Aparecerá un residuo en pantalla.
3. Arrastra el residuo al contenedor correcto.
4. Gana puntos clasificando correctamente.
5. Evita errores para mantener tus vidas.
